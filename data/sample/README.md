# サンプルデータ

このディレクトリには、解析スクリプトの動作確認用のサンプルデータが含まれています。

## ファイル

- `sample_cold.csv`: 寒冷刺激条件のサンプルデータ
- `sample_warm.csv`: 温熱刺激条件のサンプルデータ

## データ形式

CSVファイルは以下の列を含みます:

- Subject: 被験者ID
- Session: セッション番号
- index: 試行インデックス
- Trial: トライアル番号
- SOA: 刺激間隔（Stimulus Onset Asynchrony, ms）
- Answer: 回答（0: 非同時性, 1: 同時性）

## 使用方法

解析スクリプトを実行すると、ファイル選択ダイアログが開きます。このディレクトリ内のサンプルファイルを選択して動作確認できます。
