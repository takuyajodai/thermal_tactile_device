# Window size評価：中程度の方法（Moderate Method）

## 概要

中程度の方法は、フィッティング適合度を主な指標とし、統計的検定と理論的妥当性（PBR）を補助的な指標として組み合わせてWindow sizeの妥当性を評価します。実用的なバランスを提供します。

## 評価指標

### 第0段階：フィッティング適合度（主な指標）

**使用する指標**:
- **Reduced Deviance**（推奨）: 二項分布モデルに基づく適合度指標
- **Reduced χ²**（フォールバック）: Reduced Devianceが利用できない場合

**評価基準**:
- **≤ 1.0**: **valid**（良好な適合）
- **1.0 < value ≤ 3.0**: **warning**（許容範囲だが改善の余地）
- **> 3.0**: **invalid**（適合度が低い）

**解釈**:
- 1.0に近いほど、フィッティングモデルがデータを適切に説明している
- 値が大きいほど、モデルの説明力が不十分

### 第1段階：統計的検定（補助的な指標）

#### 1. Z-score法

**計算式**:
```
z_score = (Window_size - mean_window) / std_window
```

**評価基準**:
- **|z_score| ≤ 2.0**: **normal**（正常範囲内）
- **2.0 < |z_score| ≤ 3.0**: **warning**（警告範囲）
- **|z_score| > 3.0**: **abnormal**（異常、外れ値）

#### 2. IQR法（四分位範囲法）

**計算式**:
```
Q1 = 25パーセンタイル
Q3 = 75パーセンタイル
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 × IQR
upper_bound = Q3 + 1.5 × IQR
```

**評価基準**: Window_size < lower_bound または Window_size > upper_bound は**abnormal**（外れ値）

**統計的検定の統合判定**:
- **normal**: Z-scoreがnormal かつ IQR範囲内
- **warning**: Z-scoreがwarning
- **abnormal**: Z-scoreがabnormal または IQR外れ値

### 第2段階：理論的妥当性（補助的な指標）

#### ピーク・ベースライン比率（Peak-to-Baseline Ratio, PBR）

**計算式**:
```
PBR = Prob / B
```

**評価基準（B > 0の場合のみ使用）**:
- **PBR ≥ 2.0**: **normal**（ピークがベースラインの2倍以上）
- **1.5 ≤ PBR < 2.0**: **warning**（ピークがやや低い）
- **PBR < 1.5**: **abnormal**（ピークが低く、ベースラインが高い）

**B = 0の場合の特別な扱い**:
- PBRは計算しない（NaN）
- **適合度（Reduced Deviance）を主な指標として使用**:
  - 適合度 ≤ 1.0 → **normal**（B=0は理論的に妥当）
  - 適合度 > 3.0 → **abnormal**（フィッティングが不適切）
  - 1.0 < 適合度 ≤ 3.0 → **warning**（中間的なケース）

**理論的妥当性の統合判定**:
- B > 0の場合: PBRの判定結果を使用
- B = 0の場合: 適合度の判定結果を使用

### 第3段階：統合評価

**主な指標**: フィッティング適合度
**補助的な指標**: 統計的検定（Z-score、IQR）、理論的妥当性（PBR）

統合判定のルール（適合度を主な指標として、補助的な指標で調整）：

#### 補助指標の作用について

補助指標はメイン指標（適合度）に作用します：

1. **メイン指標がinvalidの場合**: 補助指標は作用しない（常にinvalid）
2. **メイン指標がwarningの場合**: 補助指標がinvalidなら、最終判定をinvalidに悪化させる
3. **メイン指標がvalidの場合**: 補助指標がinvalid/warningなら、最終判定をwarningにダウングレード

#### ケース1: 適合度がinvalid（> 3.0）
- **最終判定**: **invalid**
- **理由**: 適合度が低い場合、補助的な指標に関係なくinvalid（補助指標は作用しない）
- **例**: 被験者1（適合度=15.182）→ invalid

#### ケース2: 適合度がwarning（1.0 < value ≤ 3.0）
補助的な指標を確認：
- **補助的な指標のいずれかがinvalid** → **invalid**（補助指標が悪化させる）
- **それ以外** → **warning**
- **例**: 
  - 被験者3（適合度=2.152, 統計的検定=normal, PBR=3.7615 normal）→ warning
  - 被験者7（適合度=2.716, 統計的検定=normal, PBR=NaN（B=0））→ warning

#### ケース3: 適合度がvalid（≤ 1.0）
補助的な指標を確認：
- **補助的な指標のいずれかがinvalid** → **warning**（補助指標がダウングレード）
- **補助的な指標のいずれかがwarning** → **warning**（補助指標がダウングレード）
- **補助的な指標が全てnormal** → **valid**
- **例**: 
  - 被験者4（適合度=0.755, 統計的検定=normal, PBR=28.3443 normal）→ valid
  - 被験者9（適合度=0.243, 統計的検定=normal, PBR=NaN（B=0だが適合度が良好））→ valid

**重要なポイント**:
- **メイン指標がvalidでも、補助指標がinvalidならwarningにダウングレード**（例：適合度=0.8だが、Z-scoreが異常に大きい場合）
- **メイン指標がwarningでも、補助指標がinvalidならinvalidに悪化**（例：適合度=2.5だが、PBRが異常に低い場合）
- **メイン指標がinvalidの場合、補助指標は作用しない**（適合度が低い場合、他の指標に関係なくinvalid）

## メリット

1. **適合度を主な指標として使用**: フィッティングの品質を直接評価
2. **B=0の場合の適切な扱い**: B=0の場合、適合度を主な指標として使用し、適切に評価
3. **PBRを補助的な指標として使用**: B > 0の場合、理論的妥当性の補助的な指標として機能
4. **実用的なバランス**: 適合度、統計的検定、理論的妥当性の3つを適切に組み合わせ
5. **高速**: 平均0.105 msと実用的な速度
6. **理解しやすい**: 複雑すぎず、適度な詳細度

## デメリット

1. **理論的期待幅の計算を省略**: より詳細な理論的検証は行わない
2. **平坦度指標を使用しない**: ピーク外領域の平坦性を評価しない
3. **補正Window sizeを使用しない**: 恣意的な補正を避けるため、補正Window sizeは使用しない

## 推奨される使用場面

1. **日常的な分析**: 実用的なバランスを求める場合
2. **標準的な評価**: 多くの研究で使用できる標準的な方法
3. **計算リソースが限られている場合**: Comprehensive methodほど計算コストがかからない
4. **理論的妥当性を考慮したい場合**: Simple methodよりも詳細だが、Comprehensive methodほど複雑でない

## 他の方法との比較

- **Simple methodとの一致率**: 100.0%（15/15）
- **Comprehensive methodとの一致率**: 46.7%（7/15）

Moderate methodは、Simple methodと完全に一致する結果を示しました。これは、適合度を主な指標として使用し、PBRを補助的な指標として扱うことで、Simple methodと同じ評価基準を維持しながら、B=0の場合の扱いを改善したためです。

## 結論

中程度の方法は、適合度を主な指標とし、統計的検定と理論的妥当性（PBR）を補助的な指標として組み合わせることで、実用的なバランスを提供します。特に、B=0の場合でも適合度に基づいて適切に評価できる点が改善されました。日常的な分析や標準的な評価に適しています。
