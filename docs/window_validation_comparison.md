# Window size評価方法の比較

## 概要

3つの異なる複雑度レベルのWindow size評価方法（Simple、Moderate、Comprehensive）を比較し、それぞれの特徴、実行結果、推奨される使用場面をまとめます。

## 3つの方法の比較表

| 項目 | Simple Method | Moderate Method | Comprehensive Method |
|------|---------------|-----------------|----------------------|
| **評価指標数** | 2 | 3 | 3 |
| **実行時間（平均）** | 0.025 ms | 0.079 ms | 0.076 ms |
| **複雑度** | 低 | 中 | 中 |
| **実装の容易さ** | 非常に容易 | 容易 | 容易 |
| **理解の容易さ** | 非常に容易 | 容易 | 容易 |

### 使用する評価指標

| 指標 | Simple | Moderate | Comprehensive |
|------|--------|----------|---------------|
| **フィッティング適合度（主な指標）** | ✓ | ✓ | ✓ |
| **Z-score（補助的な指標）** | ✓ | ✓ | ✓ |
| **IQR法（補助的な指標）** | - | ✓ | ✓ |
| **PBR（補助的な指標、B>0の場合のみ）** | - | ✓ | ✓ |

**注意**: 以下の指標は除外されました（恣意的な補正、一般的でない指標のため）:
- 補正Window size
- 理論的期待幅
- 平坦度指標
- ブートストラップ
- ロバスト統計（MAD）
- 残差分析
- 感度分析
- 重み付きスコアリング

## 統合判定のロジック

### Moderate Method と Comprehensive Method の統合判定

両方の方法は、**適合度を主な指標**とし、**統計的検定と理論的妥当性（PBR）を補助的な指標**として統合判定を行います。

#### 統合判定の詳細ルール

**ケース1: 適合度がinvalid（> 3.0）**
- **最終判定**: **invalid**
- **理由**: 適合度が低い場合、補助的な指標に関係なくinvalid
- **例**: 被験者1（適合度=15.182）→ invalid

**ケース2: 適合度がwarning（1.0 < value ≤ 3.0）**
補助的な指標を確認：
- **補助的な指標のいずれかがinvalid** → **invalid**
- **それ以外** → **warning**
- **例**: 
  - 被験者3（適合度=2.152, 統計的検定=normal, PBR=3.7615 normal）→ warning
  - 被験者7（適合度=2.716, 統計的検定=normal, PBR=NaN（B=0））→ warning

**ケース3: 適合度がvalid（≤ 1.0）**
補助的な指標を確認：
- **補助的な指標のいずれかがinvalid** → **warning**（ダウングレード）
- **補助的な指標のいずれかがwarning** → **warning**
- **補助的な指標が全てnormal** → **valid**
- **例**: 
  - 被験者4（適合度=0.755, 統計的検定=normal, PBR=28.3443 normal）→ valid
  - 被験者9（適合度=0.243, 統計的検定=normal, PBR=NaN（B=0だが適合度が良好））→ valid

### 補助的な指標の統合方法

**統計的検定**:
- Z-scoreとIQRの両方を考慮
- いずれかがabnormal → abnormal
- いずれかがwarning → warning
- 両方がnormal → normal

**理論的妥当性（PBR）**:
- B > 0の場合: PBRの判定結果を使用
- B = 0の場合: 適合度の判定結果を使用（理論的妥当性の評価として）

## 評価結果の一致について

### 完全一致（100%一致率）

3つの方法が**完全に一致**している理由：

1. **同じ評価基準を使用**:
   - 全ての方法が**適合度を主な指標**として使用
   - ModerateとComprehensiveは**統計的検定（Z-score、IQR）とPBRを補助的な指標**として使用
   - SimpleはZ-scoreのみを補助的な指標として使用（PBRは使用しない）

2. **同じ統合判定ロジック**:
   - ModerateとComprehensiveは同じ統合判定ロジックを使用
   - Simpleは適合度とZ-scoreの両方がvalidの場合のみvalid

3. **B=0の場合の統一的な扱い**:
   - B=0の場合、全ての方法が適合度を主な指標として使用
   - 被験者9（B=0, 適合度=0.243）は全ての方法でvalidと判定

4. **不要な指標の除外**:
   - 恣意的な補正（補正Window size）を除外
   - 一般的でない指標（理論的期待幅、平坦度指標、ブートストラップ、MAD、残差分析、感度分析、重み付きスコアリング）を除外

## 推奨される使用戦略

### 3つの方法の違い

3つの方法は**完全に同じ評価結果**を示しますが、以下の違いがあります：

1. **Simple Method**:
   - 最もシンプル（適合度 + Z-scoreのみ）
   - 最も高速（0.025 ms）
   - 理論的妥当性（PBR）を考慮しない

2. **Moderate Method**:
   - バランスが良い（適合度 + Z-score + IQR + PBR）
   - 高速（0.079 ms）
   - 理論的妥当性（PBR）を補助的な指標として考慮

3. **Comprehensive Method**:
   - Moderate methodと同じ評価基準
   - 高速（0.076 ms）
   - 理論的妥当性（PBR）を補助的な指標として考慮

### 研究の目的に応じた選択

#### 迅速なスクリーニングが必要な場合
→ **Simple Method**（最も高速、PBRは不要）

#### 標準的な分析が必要な場合
→ **Moderate Method** または **Comprehensive Method**（理論的妥当性も考慮）

#### 計算リソースが限られている場合
→ **Simple Method**（最も高速）

#### 理論的妥当性も考慮したい場合
→ **Moderate Method** または **Comprehensive Method**（PBRを含む）

## 評価結果の解釈

### 3つの方法が完全に一致

現在の実装では、3つの方法が**完全に一致**（100%一致率）しています。これは、全ての方法が同じ評価基準を使用しているためです。

### 評価結果の解釈

- **valid**: 適合度が良好（≤ 1.0）かつ補助的な指標も正常
  - 高い信頼性、分析に含める

- **warning**: 適合度が中間的（1.0 < value ≤ 3.0）または補助的な指標のいずれかがwarning
  - 注意が必要、視覚的確認を推奨

- **invalid**: 適合度が低い（> 3.0）または補助的な指標のいずれかがinvalid
  - 信頼性が低い、分析から除外を検討

### B=0の場合の特別な扱い

- **B=0 かつ 適合度 ≤ 1.0**: valid（B=0は理論的に妥当）
- **B=0 かつ 適合度 > 3.0**: invalid（フィッティングが不適切）
- **B=0 かつ 1.0 < 適合度 ≤ 3.0**: warning（中間的なケース）
