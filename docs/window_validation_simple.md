# Window size評価：シンプルな方法（Simple Method）

## 概要

シンプルな方法は、最小限の指標のみを使用してWindow sizeの妥当性を評価します。計算が簡単で理解しやすく、実装が容易な方法です。

## 評価指標

### 1. フィッティング適合度（Goodness of Fit）

**使用する指標**:
- **Reduced Deviance**（推奨）: 二項分布モデルに基づく適合度指標
- **Reduced χ²**（フォールバック）: Reduced Devianceが利用できない場合

**評価基準**:
- **≤ 1.0**: **valid**（良好な適合）
- **1.0 < value ≤ 3.0**: **warning**（許容範囲だが改善の余地）
- **> 3.0**: **invalid**（適合度が低い）

**解釈**:
- 1.0に近いほど、フィッティングモデルがデータを適切に説明している
- 値が大きいほど、モデルの説明力が不十分

### 2. Z-score（Window size）

**計算式**:
```
z_score = (Window_size - mean_window) / std_window
```

**評価基準**:
- **|z_score| ≤ 2.0**: **valid**（正常範囲内）
- **2.0 < |z_score| ≤ 3.0**: **warning**（警告範囲）
- **|z_score| > 3.0**: **invalid**（異常、外れ値）

**解釈**:
- 他の被験者と比較して、Window sizeが異常に大きいまたは小さいかを判定
- 統計的外れ値の検出

## 統合判定

両方の指標を組み合わせて最終判定を行います：

- **valid**: 適合度とZ-scoreの両方がvalid
- **warning**: いずれか一方がwarning
- **invalid**: いずれか一方がinvalid

### 主な発見

1. **適合度による判定が主要因**:
   - Reduced Deviance > 3.0の被験者（1, 2, 5）は全てinvalid
   - Reduced Deviance ≤ 1.0の被験者（4, 6, 8, 9, 10, 11）は全てvalid
   - 1.0 < Reduced Deviance ≤ 3.0の被験者はwarningまたはvalid

2. **Z-scoreによる補正**:
   - 被験者14はReduced Deviance=1.598（warning範囲）だが、Z-score=2.255（warning）のため、最終判定はwarning
   - 被験者3はReduced Deviance=2.152（warning範囲）で、Z-score=-1.490（valid）のため、最終判定はwarning

3. **実行速度**:
   - 平均0.047 msと非常に高速
   - 大規模なデータセットでも迅速に評価可能

## メリット

1. **シンプルで理解しやすい**: 2つの指標のみを使用
2. **高速**: 平均0.047 msと非常に高速
3. **実装が容易**: 最小限のコードで実装可能
4. **既存の適合度指標を活用**: フィッティング時に既に計算されている指標を使用

## デメリット

1. **理論的妥当性を考慮しない**: PBRや補正Window sizeなどの理論的指標を使用しない
2. **詳細な検証が不足**: 平坦度指標や残差分析などの詳細な検証を行わない
3. **Bパラメータが0の場合の扱い**: B=0の場合、PBRが計算できないが、この方法では問題にならない（PBRを使用しないため）

## 推奨される使用場面

1. **迅速なスクリーニング**: 大量のデータを迅速に評価する必要がある場合
2. **初期評価**: 詳細な分析の前に、大まかな評価を行いたい場合
3. **教育・説明**: 評価方法を説明する際の入門として
4. **計算リソースが限られている場合**: 計算時間を最小限に抑えたい場合

## 他の方法との比較

- **Moderate methodとの一致率**: 60.0%（9/15）
- **Comprehensive methodとの一致率**: 46.7%（7/15）

Simple methodは、適合度が極端に悪い（> 3.0）または良好（≤ 1.0）な場合に、他の方法と一致する傾向があります。中間的な値（1.0-3.0）では、評価が異なることがあります。

## 結論

シンプルな方法は、最小限の計算でWindow sizeの妥当性を評価できる実用的な方法です。特に、フィッティング適合度が極端に悪いまたは良好な場合に有効です。ただし、より詳細な検証が必要な場合は、Moderate methodやComprehensive methodの使用を検討してください。
